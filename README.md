## 02 · About Me

I'm **Amine Oubaidi**, an **MSc Computer Science graduate (Data Engineering)** from **La Rochelle University**, working at the intersection of **deep learning research and practical software engineering**.

My work spans **computer vision, multimodal learning, sequence modelling, generative video models and ML infrastructure**. I've conducted research-oriented internships at **L3i Laboratory** and built data and automation solutions during an industry internship at **Enedis**.

- **Product mindset:** Turn complex models into maintainable workflows that address clearly defined user needs.

<summary><strong>01 / Industrial Smoke Plume Generation — VQGAN + Flow Matching</strong></summary>

<br />

A generative video research project modelling industrial smoke dynamics. Built an image preparation and foreground-isolation workflow, learned compressed visual representations with **VQGAN**, and trained a **Flow Matching** model to produce future frames from temporal context.

| Dimension | Implementation |
|:--|:--|
| **Stack** | PyTorch, VQGAN, Flow Matching, OpenCV, Weights & Biases |
| **Scale** | Industrial-smoke video clips; structured train/validation/test sequences |
| **Performance** | Reconstruction and temporal quality analysed with PSNR, SSIM and FVD; qualitative video comparisons |
| **Security** | Research workflow; no public inference API or production security certification claimed |
| **Impact** | End-to-end experimentation from raw video to latent-space sequence generation |
| **Repository** | [Source code & methodology](https://github.com/omdrift/Modelisation-panaches-de-fum-es-industrielles-par-Flow-Matching) |

**Engineering focus:** Configurable experiments, GPU training, dataset preparation, evaluation and reproducibility. The documented current VQGAN configuration uses **64×64 inputs** and **8×8×256 latents**.

</details>
